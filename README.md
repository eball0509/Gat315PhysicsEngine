## About

The Gat315PhysicsEngine is a foundational physics simulation system designed as part of the GAT 315 coursework. It aims to provide a basic yet functional framework for understanding and implementing core physics principles in a computational environment, with a strong emphasis on visual demonstration through the **Raylib library**.

---

## Features

While specific features depend on the project's progression within the GAT 315 curriculum, common features of a physics engine at this level might include:

* **Rigid Body Dynamics:** Simulation of solid, non-deformable objects.
* **Collision Detection:** Algorithms to identify when objects are intersecting.
* **Collision Response:** Methods to resolve overlaps and apply appropriate forces (e.g., impulse-based).
* **Force Accumulation:** Applying various forces (gravity, user-defined forces) to objects.
* **Integration Methods:** Numerical methods (e.g., Euler, Verlet) for updating object positions and velocities over time.
* **Basic Geometries:** Support for primitive shapes (e.g., spheres, boxes) for collision detection.
* **Raylib Integration:** Rendering of physics objects, interactive controls, and debugging visualization using Raylib.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

* **C++ Compiler:** A modern C++ compiler (e.g., GCC, Clang, MSVC) is required.
* **Raylib Library:** You'll need the Raylib library installed on your system. This typically means having the Raylib header files (`.h`) and library files (`.lib` on Windows, `.a` or `.so` on Linux/macOS) available for your compiler to find.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/eball0509/Gat315PhysicsEngine.git](https://github.com/eball0509/Gat315PhysicsEngine.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Gat315PhysicsEngine
    ```
3.  **Compile the source code:**
    You'll need to manually compile the C++ source files (`.cpp`) and link them against the Raylib library. The exact command depends on your operating system and compiler.

    Here are common examples, but you may need to adjust paths to your Raylib installation:

    **For GCC/Clang (Linux/macOS):**
    ```bash
    g++ -o Gat315PhysicsEngine main.cpp [other_cpp_files.cpp] -lraylib -L/path/to/raylib/libraries -I/path/to/raylib/includes
    ```
    * Replace `[other_cpp_files.cpp]` with any other `.cpp` files in your project.
    * `-lraylib` links against the Raylib library.
    * `-L/path/to/raylib/libraries` specifies where your Raylib library files (e.g., `libraylib.a` or `libraylib.so`) are located.
    * `-I/path/to/raylib/includes` specifies where your Raylib header files (e.g., `raylib.h`) are located.

    **For MSVC (Windows, using Developer Command Prompt):**
    ```bash
    cl /EHsc /Fe:Gat315PhysicsEngine.exe main.cpp [other_cpp_files.cpp] /I "C:\path\to\raylib\include" /link /LIBPATH:"C:\path\to\raylib\lib" raylib.lib
    ```
    * Replace `[other_cpp_files.cpp]` with any other `.cpp` files in your project.
    * `/I "C:\path\to\raylib\include"` specifies the path to Raylib header files.
    * `/link /LIBPATH:"C:\path\to\raylib\lib" raylib.lib` links against the Raylib library.

    **Important:** You must ensure your compiler can find the Raylib headers and library files. If you've installed Raylib to a non-standard location, you'll need to specify those paths in your compilation command. Refer to Raylib's official documentation for detailed installation and manual compilation instructions.
