## About

The Gat315PhysicsEngine is a foundational physics simulation system designed as part of the GAT 315 coursework. It aims to provide a basic yet functional framework for understanding and implementing core physics principles in a computational environment.

## Features

While specific features depend on the project's progression within the GAT 315 curriculum, common features of a physics engine at this level might include:

* **Rigid Body Dynamics:** Simulation of solid, non-deformable objects.
* **Collision Detection:** Algorithms to identify when objects are intersecting.
* **Collision Response:** Methods to resolve overlaps and apply appropriate forces (e.g., impulse-based).
* **Force Accumulation:** Applying various forces (gravity, user-defined forces) to objects.
* **Integration Methods:** Numerical methods (e.g., Euler, Verlet) for updating object positions and velocities over time.
* **Basic Geometries:** Support for primitive shapes (e.g., spheres, boxes) for collision detection.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

* **C++ Compiler:** A modern C++ compiler (e.g., GCC, Clang, MSVC) is required.
* **CMake (Optional but Recommended):** For easier project configuration and building.
* **Potentially a Graphics Library (e.g., OpenGL, SFML):** If the engine includes visual demonstrations, a suitable graphics library will be necessary. Check the project's dependencies if you encounter build errors related to rendering.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/eball0509/Gat315PhysicsEngine.git](https://github.com/eball0509/Gat315PhysicsEngine.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Gat315PhysicsEngine
    ```
3.  **Build with CMake (Recommended):**
    ```bash
    mkdir build
    cd build
    cmake ..
    make
    ```
    (On Windows, you might use `cmake --build .` after `cmake ..` which generates Visual Studio project files).

4.  **Manual Build (Alternative):**
    If not using CMake, you will need to compile the C++ source files directly using your compiler. Consult your compiler's documentation for specific commands.
